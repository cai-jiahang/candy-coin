# CANDY COINS content guide

This project is a reusable website master for future coursework and visual memories.

## Add or update a project

Edit `src/data/content.js`. Keep each project `id` stable because it is used in the URL.

Project media should be placed in:

```text
src/assets/projects/<project-id>/
```

Then import those files into `content.js` and add them to the project's `media` array. Empty media arrays intentionally render a placeholder.

## Add an archive memory

Place the real file in a category folder:

```text
src/assets/archive/experiments/
src/assets/archive/unfinished/
src/assets/archive/ai/
src/assets/archive/research/
src/assets/archive/future/
```

Add an object to `archiveEntries` with a unique `id`, real title, category, year and media reference. Do not add invented material merely to fill the page.

## Update the About statement

Replace the two `notes` prompts inside `renderAbout()` in `src/app.js` with personal writing. The confirmed Candy / Coins origin story can remain as the permanent opening statement.

## Add contact links

Replace the placeholder values inside `contactMethods` in `renderContact()` with real Instagram, Are.na and email details. Until then, the website deliberately shows that the links are pending.

## Brand assets

The original logo lives at `src/assets/brand/candy-coins-logo.png`. Do not redraw, replace or recolor it. The shared white flattened coin-ring markup is generated by `coinRingHtml()` in `src/app.js`.

## Run the master

The website has no external dependencies. Open `index.html` directly, or run `node serve.cjs` and visit `http://127.0.0.1:4173`.
