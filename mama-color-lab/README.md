# 马马 MAMA · COLOR LAB

藏在颜料管里的三原色小马精灵，以色彩、绘画与珍惜颜料为核心的 IP 角色设计数字展览。

在线地址：`https://cai-jiahang.github.io/candy-coin/mama-color-lab/`

本地双击 `index.html` 也可离线浏览，无需安装软件或连接网络。

## 浏览方式

- 向下滚动，依次查看世界观、角色档案、性格动作、兴趣世界与产品应用。
- 点击任意主图可进入大图查看，按 `Esc` 或点击右上角按钮关闭。
- 顶部导航可快速跳转到主要章节。
- 页面已适配电脑、平板和手机；正式展示建议使用 1440 px 以上宽屏并全屏浏览。

## 文件说明

- `index.html`：数字展览主页面。
- `assets/images`：网页使用的轻量 WebP 图片。
- 网页图片均由现有 300 dpi 图板生成，原始比赛素材未被修改。
